# DAY 2

## What we learned?
- Looping Statements(For loop, While Loop)
- Branching Statements(if-else, match-case)
- Iterables(List, Tuples, Sets, Dictionary)

## Details:
### Iterables:
- List: Ordered, Changeable and Allows Duplicate
- Tuple: Ordered, Immutable and Allows Duplicate
- Set: Unordered, Immutable and Doesn't Allow Duplicate. Fastest to search in.
- Dictionary: Ordered, Mutable and Doesn't Allow Duplicate. Implements data as Key-Value pairs.
